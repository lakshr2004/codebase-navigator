# Phase 2A Cleanup Plan

This plan records evidence before cleanup. No runtime architecture, API contract, search semantics, vector behavior, or frontend design will be changed.

## SAFE TO DELETE

| Path | Evidence | Why dead/generated | Runtime impact | Test impact |
|---|---|---|---|---|
| `package-lock.json` | Root has no `package.json`; lockfile has an empty `packages` object; authoritative frontend manifests are under `frontend/` | Accidental root-level npm artifact | None; root has no npm workflow | None; frontend uses `frontend/package-lock.json` |
| `frontend/node_modules/` | 6,257 tracked files; generated by `npm install`; dependency tree is reproduced by `frontend/package.json` and `frontend/package-lock.json` | Generated third-party install output must not be versioned | None after `npm install` | Build/E2E rerun after removal |

## SAFE TO MOVE

None identified. Runtime-cloned repositories remain under ignored `data/` because the backend currently expects that location.

## KEEP

- `frontend/package.json` and `frontend/package-lock.json`: authoritative frontend dependency/build manifests.
- `requirements.txt`: authoritative backend dependency manifest.
- All current tests: regression coverage for previously fixed behavior.
- `API.md`, `README.md`, and `docs/PRODUCTION_AUDIT.md`: current project documentation.
- `data/`: ignored runtime/fixture repository data used by existing tests and the integration fixture.
- `frontend/dist/`, Playwright artifacts, and caches locally after verification only if regenerated; they are not source files.

## NEEDS REVIEW

| Path | Evidence | Reason not deleted in Phase 2A |
|---|---|---|
| `ingestion/github.py` | No imports found, but contains a `__main__` entry point and standalone clone utility | Could be an undocumented CLI/manual workflow |
| `data/` embedded repositories | Ignored and runtime/fixture dependent | Existing integration tests and local workflows reference repository data |

The four backup implementations were subsequently removed after the user
confirmed they were unwanted copies and the repository-wide reference audit
found no runtime, test, script, configuration, or documentation references.

## DEPENDENCY AUDIT

- Backend requirements are all referenced by runtime code or external runtime behavior; no dependency is removed.
- Frontend runtime/build/test dependencies are used by the app, Vite, Tailwind/PostCSS, or Playwright; no dependency is removed.

## GITIGNORE CHANGES

Add generated/local patterns for:

- `frontend/node_modules/`
- `frontend/dist/`
- `frontend/test-results/`
- `frontend/playwright-report/`
- `frontend/.vite/`
- `.pytest_cache/`
- `coverage/`
- `*.log`

The existing `.env/`, `.venv/`, `data/`, Python cache, and Qdrant patterns remain.
